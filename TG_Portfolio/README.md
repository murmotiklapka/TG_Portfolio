# проект TG_Portfolio  
#### это телеграм бот в котором есть множество функций дающие сохранять и просматривать свои проекты

## старт хостинга
1. вставте токен тг бота из bot father в переменную TOKEN в config.py
2. запустите logic.py
3. запустите bot.py

## в тг
- можно испльзуйто /help или /start для ночяльных команд
- дальше можете экспереминтировать
  
  
  
*также в таблице prtfolio.db можно просмотреть всё*
